🔑 ربط الأداة بالموقع (مرة واحدة بس)

الأداة محتاجة "مفتاح" من GitHub عشان تقدر ترفع المنتجات والصور على الموقع. المفتاح بيتحفظ على الجهاز ده بس، ومحدش غيرك بيشوفه.

  1. ادخل على github.com بحساب redcard-eg.
  2. افتح الرابط ده: إنشاء مفتاح جديد ↗
  3. في Token name اكتب: redcard-admin، وفي Expiration اختار أطول مدة متاحة.
  4. في Repository access اختار Only select repositories، وبعدين اختار redcard-eg.github.io.
  5. في Permissions افتح Repository permissions، ولاقي Contents، وخليها Read and write.
  6. انزل تحت ودوس Generate token، وانسخ المفتاح (بيبدأ بـgithub_pat_) وحطه هنا.
الأقسام بتظهر في الموقع بنفس الترتيب ده.
